# FR-128 · Versiones del prompt de contexto

| Campo | Valor |
|---|---|
| Identificador | FR-128 |
| Nombre | Versiones del prompt de contexto |
| Épica | [E-06 · IA: contexto y decisión](../E-06-ia-contexto-y-decision/README.md) |

## Rol o actor

Administrador

## Descripción

El sistema debe permitir al Administrador crear versiones del prompt de contexto y activar una, con exactamente una activa y sin borrar ninguna.

PM-59 · 07 §11 · 06 §5.3
