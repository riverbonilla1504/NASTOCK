# FR-052 · Consulta de mi cupo

## Rol o actor

Usuario

## Descripción

El sistema debe entregar al Usuario el efectivo, el retenido, el disponible, el patrimonio, el resultado realizado y no realizado y el rendimiento de su cupo, y solo del suyo.
