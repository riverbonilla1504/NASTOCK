# FR-088 · Reglas de horario, precio y salud

| Campo | Valor |

## Rol o actor

Sistema

## Descripción

El sistema debe rechazar una operación fuera del horario regular o una compra fuera de la ventana de compras (RR-07), con una cotización más vieja que el máximo (RR-11), con el interruptor correspondiente apagado (RR-14), con el broker o los datos de mercado caídos (RR-21) o, si es compra, con un descuadre crítico abierto (RR-22).
