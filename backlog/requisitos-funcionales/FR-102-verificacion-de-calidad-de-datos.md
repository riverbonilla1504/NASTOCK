# FR-102 · Verificación de calidad de datos

| Campo | Valor |
|---|---|

| Épica | [E-06 · IA: contexto y decisión](../E-06-ia-contexto-y-decision/README.md) |

## Rol o actor

Sistema (IA principal)

## Descripción

El sistema debe excluir del ciclo, con el motivo registrado, toda candidata que incumpla completitud, actualidad, valores válidos, saltos anómalos o coherencia del precio, y debe omitir el ciclo si falla QQQ.
