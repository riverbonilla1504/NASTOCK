# FR-192 · Bandeja de notificaciones

| Campo | Valor |
|---|---|
| Identificador | FR-192 |
| Nombre | Bandeja de notificaciones |
| Épica | [E-09 · Tiempo real y notificaciones](../E-09-tiempo-real-y-notificaciones/README.md) |

## Rol o actor

Usuario, Analista y Administrador

## Descripción

El sistema debe guardar cada aviso del catálogo como notificación de su destinatario y la app debe mostrarla en una bandeja con contador de no leídas, permitiendo marcar como leídas solo las propias.

## Fuente

09 §5 · 09 §5.1 · 06 §8.1
