# FR-053 · Resumen agregado del fondo

| Campo | Valor |
|---|---|
| Identificador | FR-053 |
| Nombre | Resumen agregado del fondo |
| Épica | [E-03 · Fondo y libro contable](../E-03-fondo-y-libro-contable/README.md) |

## Rol o actor

Usuario, Analista y Administrador

## Descripción

El sistema debe entregar a toda persona activa, por bolsillo, el efectivo, el valor de las posiciones, el patrimonio, el peso actual y el peso objetivo, solo en agregados y sin revelar cupos individuales.
