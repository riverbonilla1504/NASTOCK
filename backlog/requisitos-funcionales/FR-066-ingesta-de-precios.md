# FR-066 · Ingesta de precios

| Campo | Valor |
|---|---|
| Identificador | FR-066 |
| Nombre | Ingesta de precios |
| Épica | [E-04 · Datos de mercado](../E-04-datos-de-mercado/README.md) |

## Rol o actor

Sistema y Datos de mercado (Alpaca)

## Descripción

Con el mercado en ventana, el sistema debe consultar cada 15 segundos, en una sola llamada, los precios de todo el universo y los ETFs y guardar la última cotización de cada símbolo.

## Fuente

09 §2 · 05 §6 · 05 §7 · D-24
