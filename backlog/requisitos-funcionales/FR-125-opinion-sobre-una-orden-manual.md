# FR-125 · Opinión sobre una orden manual

| Campo | Valor |
|---|---|
| Identificador | FR-125 |
| Nombre | Opinión sobre una orden manual |
| Épica | [E-06 · IA: contexto y decisión](../E-06-ia-contexto-y-decision/README.md) |

## Rol o actor

Usuario

## Descripción

El sistema debe entregar al Usuario, antes de enviar su orden manual, un veredicto favorable, neutral o desfavorable con su confianza y sus banderas, usando el último contexto vigente.

07 §8 · D-15
