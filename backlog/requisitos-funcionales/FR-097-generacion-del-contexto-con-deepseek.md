# FR-097 · Generación del contexto con DeepSeek

| Campo | Valor |
|---|---|
| Identificador | FR-097 |
| Nombre | Generación del contexto con DeepSeek |
| Épica | [E-06 · IA: contexto y decisión](../E-06-ia-contexto-y-decision/README.md) |

## Rol o actor

Sistema y DeepSeek

## Descripción

El sistema debe enviar a DeepSeek las noticias numeradas con el prompt de contexto activo y obtener, por símbolo, un resumen en español, un contexto en inglés con afirmaciones respaldadas por ids de noticia y la marca de "sin noticias".
