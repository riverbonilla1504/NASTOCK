# FR-150 · Vencimiento por tiempo

| Campo | Valor |
|---|---|
| Identificador | FR-150 |
| Nombre | Vencimiento por tiempo |
| Épica | [E-07 · Sugerencias y decisiones](../E-07-sugerencias-y-decisiones/README.md) |

## Rol o actor

Sistema

## Descripción

El sistema debe pasar a vencida toda sugerencia viva cuya hora de vencimiento llegó, revisándolo cada 30 segundos con la hora de la base de datos.

08 §1 · 05 §7 · D-11 · CB-21
