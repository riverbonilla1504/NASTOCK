# FR-177 · Llenado parcial de un bracket

| Campo | Valor |
|---|---|
| Identificador | FR-177 |
| Nombre | Llenado parcial de un bracket |
| Épica | [E-08 · Ejecución y broker](../E-08-ejecucion-y-broker/README.md) |

## Rol o actor

Sistema

## Descripción

Si la entrada de un bracket se llena parcialmente y luego se cancela, el sistema debe cancelar sus patas y cubrir lo llenado con una protección virtual con los mismos precios.

## Fuente

10 §6 · Q-12 · CB-34
