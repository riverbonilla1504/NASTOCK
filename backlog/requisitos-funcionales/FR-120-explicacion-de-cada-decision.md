# FR-120 · Explicación de cada decisión

| Campo | Valor |
|---|---|
| Identificador | FR-120 |
| Nombre | Explicación de cada decisión |
| Épica | [E-06 · IA: contexto y decisión](../E-06-ia-contexto-y-decision/README.md) |

## Rol o actor

Sistema (IA principal)

## Descripción

El sistema debe armar en código la explicación de cada decisión con piezas verificables: qué se propone, por qué ganó, qué la frena, el contexto con sus titulares enlazados y las advertencias.
