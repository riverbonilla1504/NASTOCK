# FR-048 · Registro de un retiro

| Campo | Valor |
|---|---|
| Identificador | FR-048 |
| Nombre | Registro de un retiro |
| Épica | [E-03 · Fondo y libro contable](../E-03-fondo-y-libro-contable/README.md) |

## Rol o actor

Administrador

## Descripción

El sistema debe permitir al Administrador registrar un retiro desde la Reserva o desde `arriesgadas` o `usuarios_comun`, nunca desde un cupo, por un monto que no supere el disponible de esa subcuenta; el retiro queda confirmado al registrarse.

## Fuente

PM-41 · RN-12 · RN-13 · RN-14 · CB-13 · 02 §4
