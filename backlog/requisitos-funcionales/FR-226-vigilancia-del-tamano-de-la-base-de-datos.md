# FR-226 · Vigilancia del tamaño de la base de datos

| Campo | Valor |
|---|---|
| Identificador | FR-226 |
| Nombre | Vigilancia del tamaño de la base de datos |
| Épica | [E-12 · Seguridad, auditoría y cumplimiento](../E-12-seguridad-auditoria-y-cumplimiento/README.md) |

## Rol o actor

Sistema

## Descripción

El sistema debe registrar cada semana el tamaño de la base de datos y alertar al Administrador al pasar de 350 MB.

## Fuente

06 §10 · RSG-17
