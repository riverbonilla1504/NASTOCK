# FR-093 · Freno de emergencia

| Campo | Valor |
|---|---|
| Identificador | FR-093 |
| Nombre | Freno de emergencia |
| Épica | [E-05 · Motor de políticas y configuración](../E-05-motor-de-politicas-y-configuracion/README.md) |

## Rol o actor

Analista y Administrador

## Descripción

El sistema debe permitir a un Analista o a un Administrador apagar `ia_activa` o `trading_activo` con un motivo, desde un botón visible en la barra de la app.

## Fuente

PM-56 · 03 §3 · D-28 · 11 §8
