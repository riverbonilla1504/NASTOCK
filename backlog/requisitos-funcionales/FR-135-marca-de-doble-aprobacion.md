# FR-135 · Marca de doble aprobación

| Campo | Valor |
|---|---|
| Identificador | FR-135 |
| Nombre | Marca de doble aprobación |
| Épica | [E-07 · Sugerencias y decisiones](../E-07-sugerencias-y-decisiones/README.md) |

## Rol o actor

Sistema

## Descripción

Cuando el monto de una compra de Arriesgadas alcanza `aprobacion.umbral_doble_usd`, el sistema debe marcarla con doble aprobación si hay 2 o más Analistas activos, o recortar el monto justo por debajo del umbral si hay menos.
