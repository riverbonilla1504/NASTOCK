# FR-040 · Saldos nunca negativos

| Campo | Valor |
|---|---|
| Identificador | FR-040 |
| Nombre | Saldos nunca negativos |
| Épica | [E-03 · Fondo y libro contable](../E-03-fondo-y-libro-contable/README.md) |

## Rol o actor

Sistema

## Descripción

El sistema debe impedir que el efectivo de una subcuenta de bolsillo o de cupo sea negativo y que su retenido supere a su efectivo.

## Fuente

RN-05 · 06 §4
