# FR-038 · Fondo único con subcuentas

| Campo | Valor |
|---|---|
| Identificador | FR-038 |
| Nombre | Fondo único con subcuentas |
| Épica | [E-03 · Fondo y libro contable](../E-03-fondo-y-libro-contable/README.md) |

## Rol o actor

Sistema

## Descripción

El sistema debe mantener un único fondo en USD con las subcuentas `reserva`, `arriesgadas`, `usuarios_comun`, una de `cupo` por Usuario, `externa` y `resultados`, cada una con efectivo, invertido y retenido.
