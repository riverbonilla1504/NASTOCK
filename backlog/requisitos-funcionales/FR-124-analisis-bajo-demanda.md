# FR-124 · Análisis bajo demanda

| Campo | Valor |
|---|---|
| Identificador | FR-124 |
| Nombre | Análisis bajo demanda |
| Épica | [E-06 · IA: contexto y decisión](../E-06-ia-contexto-y-decision/README.md) |

## Rol o actor

Analista

## Descripción

El sistema debe permitir a un Analista pedir el análisis de un símbolo de la lista blanca de Arriesgadas, que genera un contexto fresco y la evaluación completa de ese símbolo.

## Fuente

PM-22 · 07 §2 · D-21
