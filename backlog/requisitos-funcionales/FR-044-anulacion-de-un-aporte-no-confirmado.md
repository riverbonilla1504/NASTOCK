# FR-044 · Anulación de un aporte no confirmado

| Campo | Valor |
|---|---|
| Identificador | FR-044 |
| Nombre | Anulación de un aporte no confirmado |
| Épica | [E-03 · Fondo y libro contable](../E-03-fondo-y-libro-contable/README.md) |

## Rol o actor

Administrador

## Descripción

El sistema debe permitir al Administrador anular con motivo un aporte registrado y no confirmado, y rechazar la anulación de un aporte confirmado.

## Fuente

PM-40 · RN-10 · 08 §4
