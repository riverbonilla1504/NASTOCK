# FR-002 · Mensajes de error en español por código

| Campo | Valor |
|---|---|
| Identificador | FR-002 |
| Nombre | Mensajes de error en español por código |
| Épica | [E-01 · Cimientos y calidad continua](../E-01-cimientos-y-calidad-continua/README.md) |

## Rol o actor

Usuario, Analista y Administrador

## Descripción

El sistema debe devolver cada error con un código estable del catálogo y la app debe mostrar el mensaje en español de ese código, sin mostrar nunca el texto crudo de la base de datos.
