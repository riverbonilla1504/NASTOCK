# FR-105 · Estado en etiquetas para JEV

| Campo | Valor |
|---|---|
| Identificador | FR-105 |
| Nombre | Estado en etiquetas para JEV |
| Épica | [E-06 · IA: contexto y decisión](../E-06-ia-contexto-y-decision/README.md) |

## Rol o actor

Sistema (IA principal) y JEV

## Descripción

El sistema debe entregar a JEV un estado en inglés compuesto solo por etiquetas semánticas y afirmaciones respaldadas, sin cifras ni fechas para comparar.
