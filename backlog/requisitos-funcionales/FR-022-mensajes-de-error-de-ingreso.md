# FR-022 · Mensajes de error de ingreso

| Campo | Valor |
|---|---|
| Identificador | FR-022 |
| Nombre | Mensajes de error de ingreso |
| Épica | [E-02 · Identidad y acceso](../E-02-identidad-y-acceso/README.md) |

## Rol o actor

Usuario, Analista y Administrador

## Descripción

La app debe mostrar el mensaje definido para cada fallo de ingreso: sin invitación vigente, cuenta suspendida o de baja, sin conexión y error inesperado; si la persona cierra la ventana de Google, debe volver a la pantalla de ingreso sin mensaje.
