# FR-058 · Costo y pérdida de una venta

| Campo | Valor |
|---|---|
| Identificador | FR-058 |
| Nombre | Costo y pérdida de una venta |
| Épica | [E-03 · Fondo y libro contable](../E-03-fondo-y-libro-contable/README.md) |

## Rol o actor

Sistema

## Descripción

En toda venta, el sistema debe devolver completo el costo de lo vendido a la subcuenta que vendió y, si hay pérdida, hacer que la absorba completa esa subcuenta, sin reparto ni compensación.
