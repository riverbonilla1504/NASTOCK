# FR-056 · Ajuste contable

| Campo | Valor |
|---|---|
| Identificador | FR-056 |
| Nombre | Ajuste contable |
| Épica | [E-03 · Fondo y libro contable](../E-03-fondo-y-libro-contable/README.md) |

## Rol o actor

Administrador

## Descripción

El sistema debe permitir al Administrador registrar un movimiento de ajuste con asientos que suman cero y una justificación obligatoria.

## Fuente

PM-45 · 02 §14 · 06 §4.2
