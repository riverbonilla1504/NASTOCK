# FR-039 · Movimientos de doble partida

| Campo | Valor |
|---|---|
| Identificador | FR-039 |
| Nombre | Movimientos de doble partida |
| Épica | [E-03 · Fondo y libro contable](../E-03-fondo-y-libro-contable/README.md) |

## Rol o actor

Sistema

## Descripción

El sistema debe registrar todo cambio de saldo como un movimiento cuyos asientos suman exactamente cero, a través de una única función, y rechazar todo movimiento que no sume cero.

## Fuente

RN-04 · 06 §4.1 (L1, L2)
