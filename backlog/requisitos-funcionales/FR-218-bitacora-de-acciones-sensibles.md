# FR-218 · Bitácora de acciones sensibles

| Campo | Valor |
|---|---|
| Identificador | FR-218 |
| Nombre | Bitácora de acciones sensibles |
| Épica | [E-12 · Seguridad, auditoría y cumplimiento](../E-12-seguridad-auditoria-y-cumplimiento/README.md) |

## Rol o actor

Sistema

## Descripción

El sistema debe registrar en la bitácora cada acción del catálogo (cuentas, capital, cupos, decisiones, operación, configuración y control) con actor, rol, acción, entidad, valores anterior y nuevo y origen, sin llaves ni tokens.
