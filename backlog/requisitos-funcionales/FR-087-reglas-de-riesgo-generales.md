## Rol o actor

Sistema

## Descripción

El sistema debe rechazar toda operación que use la Reserva o `usuarios_comun` (RR-02), esté bajo la orden mínima (RR-06), tenga un destinatario no activo (RR-17) o use margen, cortos, opciones u horario extendido (RR-18).
