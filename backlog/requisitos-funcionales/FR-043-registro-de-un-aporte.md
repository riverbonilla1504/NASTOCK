# FR-043 · Registro de un aporte

| Campo | Valor |
|---|---|
| Identificador | FR-043 |
| Nombre | Registro de un aporte |
| Épica | [E-03 · Fondo y libro contable](../E-03-fondo-y-libro-contable/README.md) |

## Rol o actor

Administrador

## Descripción

El sistema debe permitir al Administrador registrar un aporte con monto, referencia y nota, que queda en estado registrado sin mover el libro.

## Fuente

PM-40 · RN-07 · 02 §3.1 · 08 §4
