# FR-077 · Porcentajes de reparto consistentes

| Campo | Valor |
|---|---|

| Nombre | Porcentajes de reparto consistentes |
| Épica | [E-05 · Motor de políticas y configuración](../E-05-motor-de-politicas-y-configuracion/README.md) |

## Rol o actor

Administrador

## Descripción

El sistema debe exigir que los tres porcentajes de reparto se cambien en una sola operación y sumen 100, y el cambio no debe mover dinero existente.

RN-02 · CB-75 · CB-78
