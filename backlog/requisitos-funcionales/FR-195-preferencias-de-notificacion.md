# FR-195 · Preferencias de notificación

| Campo | Valor |
|---|---|
| Identificador | FR-195 |
| Nombre | Preferencias de notificación |
| Épica | [E-09 · Tiempo real y notificaciones](../E-09-tiempo-real-y-notificaciones/README.md) |

## Rol o actor

Usuario, Analista y Administrador

## Descripción

El sistema debe permitir a cada persona silenciar el push de operaciones y el de alertas de mercado, y no debe permitir silenciar el de sugerencias ni el operativo de administración.

PM-02 · 09 §5.3
