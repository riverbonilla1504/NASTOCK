# FR-147 · Decisión de un Analista sobre Arriesgadas

| Campo | Valor |
|---|---|
| Identificador | FR-147 |
| Nombre | Decisión de un Analista sobre Arriesgadas |
| Épica | [E-07 · Sugerencias y decisiones](../E-07-sugerencias-y-decisiones/README.md) |

## Rol o actor

Analista

## Descripción

El sistema debe permitir a un Analista aprobar o rechazar una sugerencia de Arriesgadas y debe responder `NO_AUTORIZADO` a un Usuario o a un Administrador que lo intente.

PM-21 · D-05 · D-20
