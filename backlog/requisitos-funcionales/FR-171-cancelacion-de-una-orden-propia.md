# FR-171 · Cancelación de una orden propia

| Campo | Valor |
|---|---|
| Identificador | FR-171 |
| Nombre | Cancelación de una orden propia |
| Épica | [E-08 · Ejecución y broker](../E-08-ejecucion-y-broker/README.md) |

## Rol o actor

Usuario

## Descripción

El sistema debe permitir al Usuario cancelar una orden propia aún no llenada; si la orden ya se llenó, debe tratarla como llenada e informarlo.

PM-13 · CB-37
