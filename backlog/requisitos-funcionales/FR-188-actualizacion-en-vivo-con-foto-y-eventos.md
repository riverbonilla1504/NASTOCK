# FR-188 · Actualización en vivo con foto y eventos

| Campo | Valor |
|---|---|
| Identificador | FR-188 |
| Nombre | Actualización en vivo con foto y eventos |
| Épica | [E-09 · Tiempo real y notificaciones](../E-09-tiempo-real-y-notificaciones/README.md) |

## Rol o actor

Usuario, Analista y Administrador

## Descripción

La app debe pedir la foto por la API al abrir cada pantalla, pedir por la API el registro de cada evento que llega, ignorar los eventos con versión no mayor a la que tiene y pedir la foto completa al reconectar.
