# FR-106 · Sin datos personales hacia las IAs

| Campo | Valor |
|---|---|
| Identificador | FR-106 |
| Nombre | Sin datos personales hacia las IAs |
| Épica | [E-06 · IA: contexto y decisión](../E-06-ia-contexto-y-decision/README.md) |

## Rol o actor

Sistema

## Descripción

El sistema no debe enviar a DeepSeek ni a JEV nombres, correos, identificadores de personas o de subcuentas, montos de cupos ni notas de usuarios, y debe comprobarlo con una prueba automática.
