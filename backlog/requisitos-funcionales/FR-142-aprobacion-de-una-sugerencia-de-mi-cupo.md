# FR-142 · Aprobación de una sugerencia de mi cupo

| Campo | Valor |
|---|---|
| Identificador | FR-142 |
| Nombre | Aprobación de una sugerencia de mi cupo |
| Épica | [E-07 · Sugerencias y decisiones](../E-07-sugerencias-y-decisiones/README.md) |

## Rol o actor

Usuario

## Descripción

El sistema debe permitir al dueño del cupo aprobar una sugerencia viva validando rol, dueño, estado, vencimiento, banda de precio y motor de políticas.
