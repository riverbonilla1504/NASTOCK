# FR-004 · Proveedores simulados por integración

| Campo | Valor |
|---|---|
| Identificador | FR-004 |

| Épica | [E-01 · Cimientos y calidad continua](../E-01-cimientos-y-calidad-continua/README.md) |

## Rol o actor

Sistema

## Descripción

El sistema debe permitir elegir por variable de entorno, para cada integración (mercado, broker, noticias, contexto, JEV y push), una implementación simulada con la misma interfaz que la real.
