# FR-111 · Omisión del ciclo

| Campo | Valor |

| Épica | [E-06 · IA: contexto y decisión](../E-06-ia-contexto-y-decision/README.md) |

## Rol o actor

Sistema (IA principal)

## Descripción

El sistema debe dejar el ciclo como omitido con su motivo cuando el mercado está cerrado, la IA está pausada, el presupuesto está agotado, el fondo no tiene capital o los datos están desactualizados.
