# FR-037 · Reincorporación de una cuenta

| Campo | Valor |
|---|---|
| Identificador | FR-037 |
| Nombre | Reincorporación de una cuenta |
| Épica | [E-02 · Identidad y acceso](../E-02-identidad-y-acceso/README.md) |

## Rol o actor

Administrador

## Descripción

El sistema debe permitir al Administrador reincorporar una cuenta de baja: devolverla a activo, desbloquearla en Auth y crearle un cupo nuevo en 0, dejando cerrado el anterior con su historial.

## Fuente

PM-53 · CB-06 · D-31
