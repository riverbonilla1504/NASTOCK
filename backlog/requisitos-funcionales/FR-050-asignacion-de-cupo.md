# FR-050 · Asignación de cupo

| Campo | Valor |
|---|---|
| Identificador | FR-050 |
| Nombre | Asignación de cupo |
| Épica | [E-03 · Fondo y libro contable](../E-03-fondo-y-libro-contable/README.md) |

## Rol o actor

Administrador

## Descripción

El sistema debe permitir al Administrador mover dinero de `usuarios_comun` al cupo de un Usuario sin superar el disponible de `usuarios_comun` ni `cupos.maximo_usd`.
