# FR-173 · Venta de una posición con protección nativa

| Campo | Valor |
|---|---|
| Identificador | FR-173 |
| Nombre | Venta de una posición con protección nativa |
| Épica | [E-08 · Ejecución y broker](../E-08-ejecucion-y-broker/README.md) |

## Rol o actor

Sistema

## Descripción

Antes de vender por otra vía una posición con protección nativa, el sistema debe cancelar sus patas en el broker, esperar la confirmación y luego enviar la venta.
