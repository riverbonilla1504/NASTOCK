# FR-216 · Pantalla de rebalanceos

| Campo | Valor |

| Nombre | Pantalla de rebalanceos |
| Épica | [E-11 · Administración](../E-11-administracion/README.md) |

## Rol o actor

Administrador

## Descripción

La app debe mostrar el peso actual y el objetivo de cada bolsillo y las sugerencias de rebalanceo con sus transferencias propuestas y su explicación, y permitir aprobarlas o rechazarlas.
