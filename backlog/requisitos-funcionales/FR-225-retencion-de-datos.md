# FR-225 · Retención de datos

| Campo | Valor |

| Nombre | Retención de datos |
| Épica | [E-12 · Seguridad, auditoría y cumplimiento](../E-12-seguridad-auditoria-y-cumplimiento/README.md) |

## Rol o actor

Sistema

## Descripción

El sistema debe borrar cada día los datos que superaron su periodo de retención y no debe borrar nunca libro, órdenes, sugerencias, decisiones, señales, bitácora ni ciclos del agente.
