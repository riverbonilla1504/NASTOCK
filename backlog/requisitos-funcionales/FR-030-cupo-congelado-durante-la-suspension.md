# FR-030 · Cupo congelado durante la suspensión

| Campo | Valor |
|---|---|
| Identificador | FR-030 |
| Nombre | Cupo congelado durante la suspensión |
| Épica | [E-02 · Identidad y acceso](../E-02-identidad-y-acceso/README.md) |

## Rol o actor

Sistema

## Descripción

Mientras una cuenta está suspendida, el sistema no debe crearle sugerencias ni aceptarle órdenes, y debe mantener activas las protecciones de sus posiciones.

## Fuente

02 §11 · RR-17 · CB-46
