# FR-156 · Decisión de las ventas de liquidación

| Campo | Valor |
|---|---|
| Identificador | FR-156 |
| Nombre | Decisión de las ventas de liquidación |
| Épica | [E-07 · Sugerencias y decisiones](../E-07-sugerencias-y-decisiones/README.md) |

## Rol o actor

Analista

## Descripción

El sistema debe permitir a un Analista aprobar o rechazar cada venta de liquidación, y debe permitir aprobarla y ejecutarla aunque `trading_activo` esté apagado.

## Fuente

PM-24 · RR-14 · 08 §6
